Games×10

Ten browser games, ten different genres, zero dependencies. No build step, no npm, no CDN, and not a single image, audio or font file — every pixel is drawn to a canvas and every sound is synthesized at runtime. Each game ships a self-test that plays itself to prove it works.

Built to be read as much as played — every game is a single folder of plain ES modules over shared/kit.js. Run node tools/verify.mjs for the static gate, or open any game and call await window.__selftest() in the console to watch it test itself.
