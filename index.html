Games×10

Ten games across ten genres, built to run anywhere a browser does. There is no build step and nothing to install — no framework, no CDN, and not one image, audio or font file. Every pixel is drawn to a canvas and every sound is synthesized the moment you hear it. Each game also ships a self-test that plays the game and proves it still works.

How to read it

Every game is one folder of plain ES modules over shared/kit.js. The simulation is a pure function of state, input and a fixed timestep, so the game, its self-test and its level solver all run the exact same code.

How to check it

node tools/verify.mjs runs the static gate. tools/testbed.html plays every game's self-test in sequence. Or open any game and call await window.__selftest() in the console and watch it test itself.
